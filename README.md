# ComparUs

A simple interactive visualization comparing the population of selected European countries
to the population of US states, filled from East to West.

## How to run locally
Just open `index.html` in your browser.

## How to publish on GitHub Pages
1. Create a new repository on GitHub named `comparus`.
2. Upload this entire folder (including index.html).
3. Go to Settings → Pages → set Source to **main branch** and root `/`.
4. Save — your site will be live at:
   https://<your-username>.github.io/comparus/
